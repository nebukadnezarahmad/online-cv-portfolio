# Online CV — Nebukadnezar Ahmad

Website CV dan portofolio pribadi untuk tugas Session #4. Dibangun menggunakan HTML dan CSS murni dengan desain responsif bergaya modern editorial.

## Konten

- Header dan profil
- Tentang saya
- Pengalaman kerja dan organisasi
- Pendidikan
- Hard skills, soft skills, dan software
- Proyek dari GitHub
- Prestasi terpilih
- Form kontak dan social link

## Teknologi

- HTML5 semantik
- External CSS
- CSS Grid dan Flexbox
- Responsive media queries

## Menjalankan secara lokal

```bash
python3 -m http.server 4173
```

Buka `http://localhost:4173` di browser.

## Struktur

```text
.
├── index.html
├── styles.css
├── tests/
│   └── test_portfolio.py
└── README.md
```

## Verifikasi

```bash
python3 -m unittest tests/test_portfolio.py -v
```
